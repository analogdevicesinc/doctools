## General Description

TheMAx151isahigh-speed,easy-to-use,microprocessor(uP)compatible10-bitAnalog-to-DigitalConverter (ADC) with Track-and-Hold (T/H).Half-flash techniques allowatypicalconversiontimeof1.9uswithaTotal Unadjusted Error(TUE) of±1LSB (Max). The converter s ±5V supplies.

The MAx151 internally tracks and holds the analog inputsignal,eliminatingtheneedforanexternalT/H when digitizing high-speed AC input signals. The MAx151alsocontainsaninternal4Vreference,making the part a complete, low-cost ADc. Power consumption is typically 275mW.

TheMAx151interfacesdirectlytoaμPbyappearingas a\_memory location or Input/Output (l/o) port.Read (RD)andChipSelect(CS)inputscontrolthree-state outputs.Two interface modes ensure compatibility withmostpopularμPs.TheMAx151isavailablein both0.3"DIPandWideSOpackages.
