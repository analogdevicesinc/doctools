## DESCRIPTION

The DS9101 Multipurpose Clip offers the user a low-cost fixture that mounts an iButton ® to  a  plastic badge or,  using  an  additional  wire  or  tie  wrap,  any  object  that  provides  a  hole  for  strap-mounting.  In contrast  to  the  DS9093P/S,  the  DS9101  also  allows  mounting  iButtons  to  bags  or  other  soft-surfaced objects.

The  DS9101  is  designed  for  easy  attachment  and  detachment.  Using  a  DS9093RA  Lock  Ring,  the DS9101 can hold an iButton permanently and still allow all the flexibility of strap mounting.
