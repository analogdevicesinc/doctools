## 17.7GHz to 55GHz, Wideband, Microwave Upconverter

## GENERAL DESCRIPTION

The ADMV1355 is a highly integrated microwave upconverter optimized for wideband radio designs operating in the 17.7GHz to 55GHz RF range. Provides a compact alternative to traditional multichip solutions, significantly reducing system size, weight, and power consumption.

The integrated local oscillator (LO) signal chain accepts LO input signals in the 8.85GHz to 27.5GHz range. In the LO signal chain, there are internal amplifiers, a 2× frequency multiplier, programmable harmonic-reject filter, and phase-adjust circuitry that generates the necessary 17.7GHz to 55GHz signal to drive the inphase/quadrature (I/Q) mixer.

The ADMV1355 offers three frequency translation mixer modes: IF hybrid input, complex IF input, and baseband I/Q differential input. The IF hybrid input mode utilizes one intermediate frequency (IF) input signal in the 8GHz to 12GHz range, which then passes through an on-chip 90° IF hybrid. The IF hybrid coupler produces the necessary quadrature signals for the mixer. The complex IF input mode utilizes two quadrature IF input signals in the 1GHz to 12GHz range. The baseband I/Q differential input mode utilizes differential baseband I/Q input signals from DC to 12GHz.

Immediately following the mixer are two, switch-selectable RF output driver signal chains. The low band signal chain operates from 17.7GHz to 34GHz, and the high band signal chain operates from 30GHz to 55GHz. Each signal chain has multiple stages of signal level control and harmonic filtering.

The RF output, LO input, and IF input pins are all single-ended and matched to 50Ω impedance, and the differential baseband I/Q input pins are matched to a 100Ω differential impedance. Note that no external matching circuitry is required.

Integrated gain and frequency look-up tables (LUTs) are provided and can be addressed through the serial peripheral interface (SPI) or directly using the ADD\_Fx and ADD\_Gx ball connections to allow fast switching for frequency hopping applications.

Incorporated within the ADMV1355 is a simple SPI that can operate in either a 3-wire or 4-wire implementation. The SPI allows programming all on-chip adjustable functions, such as gain control, LO feedthrough adjustment, sideband rejection optimization, tunable filters, general-purpose logic outputs, and LUTs.

The ADMV1355 upconverter is offered in a 120-ball CSP\_BGA package that supports heat sinking either from the top of the package or through the bottom of the printed circuit board (PCB). Either method of heat sinking has similar thermal performance and is acceptable to efficiently control the T C . The ADMV1355 operates over the -40°C to +95°C temperature range.

## CHIP OVERVIEW

The ADMV1355 is a highly integrated microwave upconverter designed for wideband radio systems operating across a broad RF frequency range of 17.7GHz to 55GHz. The device supports singleended IF and complex IF inputs up to 12GHz, enabling seamless integration with modern high-speed data converters and extending their effective frequency coverage into the millimeter-wave spectrum.

The chip incorporates a fully configurable architecture that includes an I/Q mixer, a LO signal chain, two RF signal chains, an IF signal chain, and baseband I/Q signal chain, all of which are configurable via a simple SPI. This level of integration minimizes the external component count while offering maximum design flexibility.

With its compact, 6mm × 6.5mm footprint, wideband capabilities, and configurable signal chains, the ADMV1355 is ideally suited for next generation, high data-rate systems requiring low size, weight, and power (SWaP) without compromising on system performance.

## POWER-UP SEQUENCE

To power up and initialize the ADMV1355, take the following steps and refer to the Timing Diagrams Overview section and Figure 180 for more information:

1. Ensure that all digital logic inputs are logic level low.
2. Power on all supply voltages simultaneously, with a rise time of 1ms or longer.
3. Once the supplies are stable, set RST to logic level high.
4. Program the nonvolatile memory (NVM) load instructions.
5. Program the necessary registers for the intended chip operation.
6. Set CEN to logic level high.

## POWER-DOWN SEQUENCE

There are three possible power-down options available for the ADMV1355. One power-down option removes all power from the chip, and the other two power-down options disable the chip, causing it to enter low power mode.

## Full Power-Down

To fully power down the chip, take the following steps and refer to Figure 183 for more information:

1. Set CEN to logic level low.
2. Set all other logic inputs to logic level low.
3. Power off all supply voltages.

## Chip Disable with CEN

To disable the chip and enter low power mode while the supply voltages are still powered on, bring CEN to logic level low. Bringing CEN to logic level low causes the chip to power off most of the RF circuits within the chip. Refer to Figure 182 for more information.

## Chip Disable with SPI

Another option for disabling the chip and entering low power mode while the supply voltages are still powered on is to set Register 0x13E, Bit 0 to 1.

## SPI

The ADMV1355 utilizes the SPI for communication to configure the chip settings. The SPI can be implemented in either 3-wire or 4-wire configurations, supports 1.8V logic levels, and SCLK frequencies up to 100MHz.

The SPI consists of digital inputs and outputs. CHIP\_ADD0, CHIP\_ADD1, SCLK, and CS are the digital inputs. SDIO is bidirectional and can be an input or output, depending upon the type of SPI operation being performed, and SDO is a digital output that remains in a high impedance state unless a read operation is being performed. CS is an active low digital input and must be asserted low during a SPI instruction. Be sure to deasserted CS at the end of a SPI instruction.

The chip address inputs, CHIP\_ADD0 and CHIP\_ADD1, can be used in multichip systems to assign an address to a particular chip. This feature allows up to four chips to share SCLK, SDIO, SDO, and CS connections. To set a chip address input to 0, ground the ball or add a 0Ω pull-down resistor. To set a chip address input to 1, leave it floating, and the internal 15kΩ resistor will set it to a logic level high. The assigned chip address modifies the SPI Communications Frame Bits[21:20].

For single SPI instructions, the communications frame is 24-bits wide and consists of a 16-bit header and 8 bits of data. The header contains a R/W bit, a broadcast (BR) bit, two chip address bits, and 12 register address bits. Both the header and data are organized MSB first and must be shifted in on SDIO with the chip sampling the logic level on the rising edge of SCLK. See Figure 179 for the SPI communications frame.

Set the R/W bit to 0 for a write operation and set the R/W to 1 for a read operation. Set the BR bit to 0 for single chip SPI instructions and set this bit to 1 to have all chips, regardless of their chip address, respond to a SPI instruction. For read operations, the BR bit must only be set to 0.

For a read operation when using a 3-wire SPI, the SDIO changes from an input to an output after the last header SCLK rising edge. The data is then shifted out on SDIO, with the logic level changing on the falling edge of SCLK, so that it can be sampled on the next rising edge of SCLK. When CS is deasserted, SDIO changes back to a digital input.

For a read operation when using a 4-wire SPI, the SDO transitions from a high impedance state to an active output, after the last header SCLK rising edge. The data is then shifted out on SDO, with the logic level changing on the falling edge of SCLK, so that it can be sampled on the next rising edge of SCLK. When CS is deasserted, SDO returns to a high impedance state.

The ADMV1355 supports SPI streaming that minimizes the SPI instruction time. During a SPI streaming instruction, CS is asserted low, a single 16-bit header instruction is given, followed by multiple bytes of data, and then CS is deasserted to end the instruction. Sequential register addresses are assumed in ascending or descending order based on how Register 0x000, Bit 5 and Bit 2 are set. Note that the default order is descending addresses.

If CS is deasserted during any header portion of a SPI instruction, the operation is ignored. If CS is deasserted during a data portion of a SPI instruction, then that data is ignored. For SPI streaming operations, any complete bytes (8 bits) of data are accepted by the chip, but a partial byte is ignored.

See the Timing Diagrams Overview section, the Power-Up and Apply the Digital Inputs section, the Initialization SPI Instructions section, the Chip Enable and Operation section, the Chip Disable and Reset section, and the Chip Disable and Power-Down section for additional timing information and refer to the ADI-SPI, Serial Control Interface Standard (Rev 1.0) for more information on SPI and communications protocol.

## NVM

The ADMV1355 contains a simple NVM that is used to store factory calibration values to minimize part to part variation. The values in the NVM set the chip bias current, trim the internal analog-to-digital converter (ADC), and trim the internal temperature sensor. At chip power-up, it is recommended to ensure that the NVM has loaded its values into the correct shadow registers. The NVM is static and can not be modified by the user.

## NVM Health Check

To confirm the NVM values have loaded, use the following NVM health check instructions:

1. Shadow Register 0x033 by doing the following:
- Set Register 0x07B to 0x33 value.
- Read Register 0x07B, it should return 0x33.
- Read Register 0x07C, it should return a nonzero value.
2. Shadow Register 0x034, by doing the following:
- Set Register 0x07B to 0x34 value.
- Read Register 0x07B, it should return 0x34.
- Read Register 0x07C, it should return a nonzero value.
3. Shadow Register 0x037 by doing the following:

## LO NULLING

In a RF system, the LO leakage at the output of a mixer can degrade the spectral purity and modulation accuracy of the transmitted signal. The ADMV1355 supports two methods of LO nulling to suppress the unwanted LO leakage that can appear at the RF output.

## Automatic LO Nulling

The ADMV1355 includes an automatic LO nulling loop that uses an internal ADC, envelope detector, and calibration logic to measure and then minimize the LO leakage. The automatic LO nulling is supported in IF hybrid and complex IF modes and for LO frequencies from 12.5GHz to 27.5GHz. Because the LO leakage varies with frequency, temperature, supply voltage, and device tolerance, rerunning automatic LO nulling after configuration changes ensures optimal performance.

To run the automatic LO nulling, ensure that the LO signal is enabled at the required frequency and that the device is configured for the required input mode. Set the following registers sequentially to run the automatic LO nulling loop:

1. Set Register 0x302 to 0x02 to reset the internal ADC.
2. Set Register 0x300 to 0x09 to enable the internal ADC and ADC clock.
3. Set Register 0x306 to 0x02 to reset the LO nulling loop.
4. Set Register 0x305 to 0x20 to enable the LO nulling loop.
5. Set Register 0x13E to 0x00 to power up the ADC reference.
6. Set Register 0x2A7 to 0x00 to set the ADC multiplexer for LO nulling.
7. When using RF high band, set Register 0x306 to 0x12 and when using RF low band set Register 0x306 to 0x22. Register 0x306 is used to tap the envelop detector for the required RF frequency band.
8. Set Register 0x302 to 0x22 to set the LO nulling current using Register 0x304.
9. For LO nulling current optimum setting, set Register 0x304 to 0x1F. The register value can be tuned for the best LO nulling results at different frequencies.
10. Set Register 0x302 to 0x26 to enable the automatic LO nulling functionality.

Then, wait for 1ms and set the following registers sequentially to turn off the automatic LO nulling loop:

1. Set Register 0x302 to 0x22 to turn off the automatic LO nulling.
2. Set Register 0x306 to 0x02 to disable the envelope tapping.
3. Set Register 0x300 to 0x00 to disable the internal ADC and the ADC clock.

## Manual LO Nulling

The ADMV1355 also supports manual LO nulling in IF hybrid and complex IF modes for applications requiring custom optimization or when automatic LO nulling cannot be executed during normal operation. To use manual LO nulling, disable the automatic LO nulling loop, by setting Register 0x305 to 0x03, and then use Register 0x808 and Register 0x809 to manually make adjustments to the internal LO nulling currents. Note that Register 0x808 and Register 0x809 use a twos complement format where 0x00 is zero correction, 0x7F is maximum positive current, and 0x80 is maximum negative current. These values are adjusted iteratively while monitoring LO leakage externally to achieve the desired LO nulling level.

To start manual LO nulling, ensure that the LO signal is enabled at the required frequency and that the device is configured for the required input mode. The following optimization sequence can be used to achieve effective LO nulling:

1. Initialize Register 0x808 and Register 0x809 by setting both to 0x00, which establishes a known starting point and ensures a stable LO leakage measurement setup prior to optimization.
2. Sweep Register 0x808 using four signed coarse values (for example: -64, -32, +32, +64) while holding Register 0x809 constant at its initialize value. For each programmed value, allow a sufficient settling time and record the corresponding LO leakage power in dBm.
3. Convert the measured LO leakage values from dBm to linear
4. power. Using these linear values, perform a second-order polynomial curve fit of the form by using the following equation: y = Ax 2 + Bx + C where x represents the signed register value. y represents the measured linear power.
4. Determine the minimum of the fitted curve by taking the derivative and solving for the following equation: x 0 = - ( B /2 A ).
5. Round the computed value to the nearest valid signed integer and ensure that it is within the allowable range (-128 to +127).
6. Program Register 0x808 with the computed optimal value.
7. Sweep Register 0x809 using the same set of coarse signed values (-64, -32, +32, +64) while holding the optimized value of Register 0x808 fixed. 8. Program Register 0x809 with the computed optimal value. At this stage, both registers contain coarse-optimized settings that significantly reduce the LO leakage.
9. To further improve LO leakage suppression, perform a fine optimization of Register 0x808. Sweep the four values centered

## THEORY OF OPERATION

## IF HYBRID SIGNAL CHAIN

The IF hybrid signal of the ADMV1355 supports frequencies from 8GHz to 12GHz and consists of a 90° hybrid. The IF\_I and IF\_Q outputs from the hybrid are fed to the mixer through fine adjust quadrature amplitude correction blocks. Refer to Figure 188 for representation of the IF signal chain. To enable the single-ended IF hybrid signal chain, set Register 0x602 to 0x08.

The IF\_HYB input is internally DC-coupled with a 50Ω single-ended impedance. When the IF\_HYB is not used, the IF\_HYB ball can be left floating. To disable the single-ended IF hybrid signal chain, set Register 0x602, Bit 3, to 0.

## COMPLEX IF SIGNAL CHAIN

The complex IF signal of the ADMV1355 supports frequencies from 1GHz to 12GHz, and each of IF\_I and IF\_Q paths consist of a low frequency signal chain ranging from 1GHz to 4GHz and a high frequency signal chain ranging from 3GHz to 12GHz. The ADMV1355 allows users to select the required path for their input frequency. The IF\_I and IF\_Q inputs are fed to the mixer through fine adjust quadrature amplitude correction blocks. Refer to Figure 188 for representation of the complex IF signal chain. To enable the complex IF low frequency signal chain, set Register 0x602 to 0x02. To enable the complex IF high frequency signal chain, set Register 0x602 to 0x04.

The IF\_I and IF\_Q inputs are internally DC-coupled with a 50Ω single-ended impedance. When the IF\_I and IF\_Q are not used, the IF\_I and IF\_Q balls can be left floating.

To disable the complex IF low frequency signal chain, set Register 0x602, Bit 1, to 0. To disable the complex IF high frequency signal chain, set Register 0x602, Bit 2, to 0.

## MIXER OVERVIEW

The ADMV1355 contains a sideband rejecting, up converting I/Q mixer with excellent linearity and noise figure. The necessary LO signals, 2×LO\_I and 2×LO\_Q, to drive the mixer come from the LO signal chain. The quadrature inputs from the IF signal chain and I/Q baseband signal chain, IF\_I and IF\_Q, also feeds into the mixer. The output from the mixer, RF\_C, is then used to drive the RF signal chains. The mixer supports RF output and 2×LO input frequencies up to 55GHz. Figure 189 shows the mixer.

## MIXER SIDEBAND SELECTION

The ADMV1355 mixer sideband can be selected by swapping the mixer LO inputs, 2×LO\_I and 2×LO\_Q. To swap these inputs, use Register 0x806, Bit 5. When the RF frequency &lt; the 2×LO frequency, set Bit 5 to 0 for the lower sideband, and when the RF frequency &gt; the 2×LO frequency, set Bit 5 to 1 for upper sideband.

## DSA1

The DSA directly after the mixer signal chain in the RF signal chains is DSA1. This attenuator offers 16 states, 0dB to 15dB, with 1dB steps. The attenuation is proportional to the value programmed.

When using the bypass registers (Register 0x28A, Bit 0, set to 1), use Register 0x28B, Bits[3:0], to set the DSA1 state. When not using the bypass registers (Register 0x28A, Bit 0, set to 0), use Register 0x600, Bits[3:0], to set the DSA1 state.

## DSA2

The DSA directly after DSA1 in the RF signal chains is DSA2. This attenuator offers 16 states, 0dB to 15dB, with 1dB steps. The attenuation is proportional to the value programmed.

When using the bypass registers (Register 0x28A, Bit 0, set to 1), use Register 0x28B, Bits[7:4], to set the DSA2 state. When not using the bypass registers (Register 0x28A, Bit 0, set to 0), use Register 0x600, Bits[7:4], to set the DSA2 state.

## THEORY OF OPERATION

## RF TUNABLE LPFS

Both the low-band and the high-band RF signal chains contain a tunable LPF to help with sideband rejection. Each tunable LPF contains 4 bits, or 16 states, that control the cutoff frequency.

The cutoff frequency is inversely proportional to the LPF value programmed.

When using the bypass register (Register 0x2A0), set Bit 4 to 1, and then program the intended LPF value into Bits[3:0]. When not using the bypass register (Register 0x2A0), set Bit 4 to 0, and then use Register 0x80B, Bits[3:0], or the frequency LUT.

When using either Register 0x80B or the frequency LUT, the lowband tunable LPF has three control bits (0 to 7), and the value programmed is multiplied by 2 (shifted left by one position). For example, when Register 0x80B, Bits[3:0], are set to 7, the effective LPF value is 14.

When using either Register 0x80B or the frequency LUT, the highband tunable LPF retains the full four control bits.

## RF TUNABLE HPF

The high-band RF signal chain contains a tunable HPF to help with sideband rejection. The tunable HPF contains 6 bits, or 64 states, that control the cutoff frequency. The cutoff frequency is inversely proportional to the HPF value programmed.

When using the bypass register (Register 0x2A1), set Bit 7 to 1, and then program the intended HPF value into Bits[5:0]. When not using the bypass register (Register 0x2A1), set Bit 7 to 0, and then use Register 0x80B, Bits[7:4], or the frequency LUT.

When using either Register 0x80B or the frequency LUT, the tunable HPF has four control bits, and the value programmed is multiplied by 4 (shifted left by two positions). For example, when Register 0x80B, Bits[7:4], are set to 15, the effective HPF value is 60.

## SIDEBAND REJECTION OPTIMIZATION

The sideband rejection capability of a mixer is defined as the ability to suppress the unwanted sideband (image sideband) that would otherwise appear at the output RF frequency. For example, if the intended IF input frequency is 8GHz, the 2×LO\_I and 2×LO\_Q mixer 2×LO frequencies are 28GHz, and if the desired RF output frequency is 36GHz, the unwanted image sideband appears at 20GHz.

Imperfections in the quadrature phase imbalance of the mixer LO signals (ideal 90°), amplitude imbalance between the mixer I/Q paths (ideal 0dB), as well as imbalance in the IF input hybrid network, may cause a residual unwanted sideband to appear at the mixer RF output. To overcome these imperfections and optimize the sideband rejection capability of the ADMV1355, the phase of the mixer LO signals and the amplitude of the mixer inputs can be finely adjusted.

The adjustable phase shifters, PH\_I and PH\_Q, in the LO signal chain allow correction of quadrature phase imbalance between the 2×LO\_I and 2×LO\_Q signals. Each phase shifter has a typical 0.6° step size and a 20° tuning range across 32 states. Use Register 0x806, Bits[4:0], to adjust the phase of 2×LO\_I, and use Register 0x805, Bits[6:2], to adjust the phase of 2×LO\_Q.

The IF\_I and IF\_Q input signals to the mixer feed through fine-adjust DSAs, DSAI and DSAQ. These attenuators allow for small 0.1dB steps and 1.5dB total amplitude control to optimize the sideband rejection capability of the ADMV1355. Use Register 0x80A to adjust these attenuators. Bits [3:0] set DSAI, and Bits[7:4] set DSAQ.

When applying an IF input frequency and observing the RF output power level, there are various options to perform sideband rejection optimization. See the Sensitivity Guided Optimization section and the Coarse and Fine Sweep Optimization section for two possible options.

## Sensitivity Guided Optimization

The first option for performing sideband rejection optimization uses sensitivity analysis to assist in making decisions to narrow the scope of possible optimization values. To perform this optimization, apply an IF image frequency and take the following steps while measuring the RF output power at the image frequency:

1. Set both PH\_I and PH\_Q to 15.
2. Set both DSAI and DSAQ to 0.
3. Step through the DSAI values starting from 0. Stop sweeping when a local minima for the RF output power has been achieved and retain the DSAI value that provides the local minima.
4. Repeat Step 3 for DSAQ.
5. Set PH\_I to 14 and then 16 to determine the optimum direction to step through. If PH\_I = 14 provides a better result than PH\_I = 16, then step through the values from 13 to 0; otherwise, step through values 17 to 31. Stop sweeping when a local minima for the RF output power has been achieved and retain the PH\_I value that provides the local minima.
6. Repeat Step 5 for PH\_Q.
7. With the values determined in Step 3 to Step 6 for DSAI, DSAQ, PH\_I, and PH\_Q, further optimization may be possible by adjusting each ±1 value.

## THEORY OF OPERATION

## Coarse and Fine Sweep Optimization

The second option for performing sideband rejection optimization uses a coarse sweep followed by a fine sweep to determine the optimization values. To perform this optimization, apply an IF image frequency and take the following steps while measuring the RF output power:

1. Set both PH\_I and PH\_Q to 0.
2. Set DSAQ to 0. Step through the DSAI values starting from 0 to 15. Record the RF output power for each value.
3. Set DSAI to 0. Step through the DSAQ values starting from 0 to 15. Record the RF output power for each value.
4. Pick the combination of values from Step 2 and Step 3 that provide the lowest RF output power. Note, that one fine step DSA value will be zero.
5. Perform a nested coarse sweep of PH\_I and PH\_Q for values 0, 4, 8, 12, 16, 20, 24, and 28. There are 64 combinations of those values for both phase shifters that are tested. Record the combination of values that provides the lowest RF output power.
6. Use the combination of values determined in Step 5 to then determine the fine sweep range by adding and subtracting 4 from each value. Perform a nested fine sweep of PH\_I and PH\_Q for these values. For example, if Step 5 yielded PH\_I = 16 and PH\_Q = 12, then the fine sweep range for PH\_I is 12 to 20, and the fine sweep range for PH\_Q is 8 to 16. Excluding the coarse values from the fine sweep, there are an additional 80 combinations of fine sweep values. Pick the combination of values that provides the lowest RF output power.

## TOTAL GAIN CONTROL

The typical total available gain (attenuation) control for each type of configuration that can be implemented with the ADMV1355 is 30dB.

## RF GAIN POLICY

The RF gain (attenuation) policy for ideal mixer performance is to keep all DSAs at their maximum gain state.

To optimize output P1dB and output IP3 performance, set the attenuation by introducing attenuation in DSA1, followed by DSA2. Applying attenuation in this order ensures that the signal level presented to the downstream RF stages is appropriately managed while minimizing degradation of the linearity of the system. By prioritizing attenuation in DSA1 before DSA2, the cascade linearity of the signal chain is preserved, resulting in improved compression and intermodulation performance.

## ADC CONFIGURATION

The ADMV1355 includes an on-chip, ADC that can capture the temperature sensor value. The value can then be read back using the SPI via Register 0x30D.

To set up the automatic ADC configuration, take the following steps:

1. Set Register 0x302 to 0x02 to enable the ADC\_RESET.
2. Set Register 0x300 to 0x09 to enable the ADC configuration and to enable ADC\_CLK\_EN.
3. Set Register 0x306 to 0x02 to enable LON\_RESET, which resets the internal registers in LO nulling block.
4. Set Register 0x13E to 0x00 to make sure ADC\_REF\_PD and TEMP\_SENSOR\_PD are set to normal operation.
5. Set Register 0x2A7 to 0x01 to set ADC\_MUX\_SELECT for the temperature sensor.
6. Set Register 0x302 to 0x06 to enable LON\_AUTO\_EN and start the ADC.
7. Read Register 0x30D (ADC\_OUT) for the temperature sensor value.

## TEMPERATURE SENSOR

The ADMV1355 contains an on-chip temperature sensor that allows monitoring of the chip temperature. The temperature sensor output can be sampled using the on-chip ADC, and the value can then be read back via the SPI.

Follow the instructions in the ADC Configuration section for information on setting up the ADC and reading back the temperature sensor value.

To estimate the T C of the ADMV1355, use the following equation: T C = -5 6 ×ADC\_CODE + 173 (3) where ADC\_CODE is what the chip reads back from the ADC\_OUT bits (Register 0x30D, Bits[7:0]).

## RECOMMENDED PCB LAYOUT

The ADMV1355 package type is a ball grid array that allows for a high pin count in a small footprint. The exposed balls on the underside of the package are intended to be soldered to a low thermal and electrical impedance ground plane. Typically, the PCB contains a solder mask defined land pattern for each ball to ensure proper solder containment and attachment.

Care must be taken with the RF trace routing escape plan for a particular implementation. In order of precedence, it is recommended to prioritize the RF traces, followed by the power supply pins, and then the digital logic connections.

The RF connections into and out of the ADMV1355 are near the edge of the package to ease the escape plan. Inner layer trace stripline routing is encouraged, particularly for applications where RF isolation performance metrics are important. Regardless of the type of RF traces employed in a PCB design, it is generally recommended to have via stitching run parallel to either side of the RF traces. The via stitching can be either through-board type vias or blind layer-to-layer vias.

Ideally, the ground connection balls are connected to the throughboard type vias to maximum the heat transfer from the package to the PCB thermal plane. Refer to the Thermal Resistance section for more information on the thermal performance metrics of the ADMV1355.

The ADMV1355 evaluation board utilizes the recommendations listed within this section, and this section is a good starting point for many applications. Refer to the ADMV1355-EVALZ user guide for more information regarding the evaluation board.
