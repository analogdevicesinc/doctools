## General Description

The MX7582 is a complete,calibrated 4-channel 12-bit A/Dconverterwhichmaintains true12-bitperformance adjustments.Inaddition,each1oousconversionincludesanauto-zerocyclewhichreduceszeroerrorsto typically below 100uV.

CHIPSELECT,READ,and WRITEinputs areincluded for easymicroprocessorinterfacingwithoutadditionallogic. 2-byte, 12-bit conversion data is provided over an 8-bit three-stateoutputbus.Eitherbytemaybereadfirst. Two addressbitscontrol the 4-channel input multiplexer.

TheMx7582's analog inputrange is 0Vto+5Vwhen using a+5V reference.Allfour high-impedance input channels have excellent matching (typically 0.05LSB).
