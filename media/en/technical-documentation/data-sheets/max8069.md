## General Description

The MAX8069 is a 1.2V temperature-compensated voltage reference. It uses the bandgap principle to achieve excellent stability and low noise at reverse currents down to  60µA. The MAX8069 also features excellent stability, freedom from oscillation. The MAX8069 is a functional alternative to Maxim's ICL8069 with an identical pinout.

Analog-to-Digital Converters
