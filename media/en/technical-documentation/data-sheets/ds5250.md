## High-Speed Secure Microcontroller

## General Description

The DS5250 is a highly secure, four clocks-permachine cycle, 100% 8051-instruction-set-compatible microprocessor in Maxim's secure microcontroller family. It  was  designed to be the cryptographic engine of PIN pads, financial terminals, and any other application in  which  data  security  is  paramount.  A  key  feature  of the device is that it encrypts its program memory and optionally its data memory with a hardware-based single- or triple-DES (data encryption standard) algorithm, making it almost impossible to extract information. It also implements block cipher encoding that uses block addresses to modify the encrypted data, further strengthening security. This makes the device ideal for storage and transmission of passwords, personal identification  numbers, encryption keys, and other highly confidential information.
