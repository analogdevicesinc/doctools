## 5V/3.3V/3V 5A Step-Down, PWM, Switch-Mode DC-DC Regulators

## \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_General Description

The MAX787/MAX788/MAX789 are monolithic, bipolar, pulse-width modulation (PWM), switch-mode, step-down DC-DC regulators. Each is rated at 5A. Very few external components are needed for standard operation because the power switch, oscillator, feedback, and control circuitry are all on-chip. Employing a classic buck topology, these regulators perform high-current step-down functions.

The MAX787/MAX788/MAX789 have excellent dynamic and transient response characteristics, while featuring cycle-by-cycle current limiting to protect against overcurrent faults and short-circuit output faults. They also have a wide 8V to 40V input range.

- ' Input Range: Up to 40V

- ' 100kHz Switching Frequency

- ' Excellent Dynamic Characteristics

- ' Few External Components

- ' 8.5mA Quiescent Current

- ' TO-220 Package

Each regulator is available in a 5-pin TO-220 package. These devices have a preset 100kHz oscillator frequency and a preset current limit of 6.5A. See the MAX724/ MAX726 data sheet for more applications information.
