## iButton DESCRIPTION

The  DS1995  Memory  iButton  operates  nearly identically  to  the  DS1996.  The  main  differences are: 16 Kbits of memory organized as 64 pages of 32 bytes and a family code of 0A hexadecimal. For further details, refer to the DS1996 data sheet.
