## SC-USB-SPI-PICO

## General Description

SC-USB-SPI is an adapter used for converting a computer's USB interface connection to the serial parallel  interface (SPI) used by the SC1905 and the SC1894 (RFPAL).

It is recommended for prototypes debug and/or programming linearizer during manufacturing.

RFPAL GUI installation package installs necessary drivers in order to work on Windows ®  7 or Windows 10 with USB 2.0 or USB 3.0.
