## General Description

The MAX5138 evaluation kit (EV kit) provides a proven design to evaluate the MAX5138 16-bit, low-power, digital-to-analog converter (DAC). The EV kit also includes Windows ® 2000/XP- and Windows Vista ® -compatible software that provides a simple graphical user interface (GUI) for exercising the features of the MAX5138.

The MAX5138 EV kit PCB comes with a MAX5138BGTE+ installed. Contact the factory for free samples of the pincompatible MAX5139GTE+ to evaluate this device.

## Detailed Description of Software

The main window of the evaluation software (Figure 1) displays the voltage and code for the DAC input and output registers. In addition, the main window has two tabs. The Load DAC tab sheet controls all the DAC loading features of the MAX5138. The Operating Modes tab sheet (Figure 2) controls all the DAC modes of  the  MAX5138. The Load Setting(s) button must be pressed in order to write the corresponding mode settings to the DAC.

## Software Reset

Press the Reset All Registers button to reset the MAX5138's registers and GUI to the power-on-reset (POR) state. This can be done at any time and is highly recommended after the advanced user interface is used.

## Advanced User Interface

A manual serial interface can be used by advanced users by selecting Options | Interface (Advanced Users) from the menu bar.

For SPI, click on the 3-wire interface tab shown in Figure 3. Enter data into the Data bytes to be written edit box and press the Send Now button.

## Detailed Description of Hardware

The MAX5138 EV kit provides a proven layout for the MAX5138. An on-board analog output signal header (H2),  on-board digital input/output signal header (H3), and jumpers to disconnect the on-board microcontroller are all included on the EV kit.

## Reference

At power-up, the MAX5138 EV kit defaults to using the internal 2.440V reference.

To use AVDD as the reference, place the shunt on jumper JU9 in the 2-3 position. For off-board external references, connect a user-supplied reference voltage to REFIN and remove the shunt on jumper JU9. Type in the reference voltage value in the Set Vref edit box and press the Set Vref button. The MAX5138 EV kit software uses the value in the Set Vref edit box to calculate  the  input  and  output  register  voltage  values  and does not affect any commands to the part.

## User-Supplied SPI Interface

To use the MAX5138 EV kit with a user-supplied SPI interface, first move the shunts of jumpers JU1-JU5 and JU7 to the 2-3 position. Then apply an external 2.7V to 5.25V power supply to DVDD. Lastly, connect CS ,  SCLK, DIN, and GND signals to the corresponding pins of header H3.

## User-Supplied Power Supplies

The MAX5138 EV kit is powered completely from the USB port by default. Before connecting a user-supplied power supply greater than 3.6V on DVDD, the on-board microcontroller must be disconnected. First, move the shunts of jumpers JU1-JU5, JU7, and JU8 to the 2-3 position.  Then,  apply  an  external  2.7V  to  5.25V  power supply to the corresponding DVDD and AVDD pads. For optimum performance, use separate supplies. Lastly, see the User-Supplied SPI Interface section for interface connections, if applicable.
