✷✂✸✂✹✻✺☎✼✾✽✝✿✂❀❂❁❄❃✔✸✖❅✡✺☎❆✎❅✢✺❇✸✂❈❊❉●❋✝❍☞✸ ✂ ☞ ■✾✳✂ ❏✡❑ ▲▼☞ The  MAX3658A outputs are back terminated with 75 Ω . To facilitate interface with 50 Ω equipment, the MAX3658A  EV  Kit  places  external  150 Ω termination resistors  in  parallel  with  each output so that the EV Kit will match a 50 Ω environment.

Note that the output load has a direct effect on the overall gain  and  output  signal  swing.  Because  of  the  external 150 Ω resistors and the 50 Ω environment, the overall gain is reduced by 33%. If matching a 50 Ω environment is not critical,  higher  gain  can  be  achieved  by  increasing  the load resistance.
