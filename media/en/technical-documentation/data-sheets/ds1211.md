## DESCRIPTION

The DS1211 Nonvolatile Controller x 8 Chip is a CMOS circuit which solves the application problem of converting  CMOS  RAMs  into  nonvolatile  memories.  Incoming  power  is  monitored  for  an  out-oftolerance condition.  When such a condition is detected, the chip enables are inhibited to accomplish write protection and the battery is switched on to supply RAMs with uninterrupted power.  Special circuitry uses  a  low-leakage  CMOS  process  which  affords  precise  voltage  detection  at  extremely  low  battery consumption.

By combining the DS1211 nonvolatile controller/decoder  chip and lithium batteries,  nonvolatile  RAM operation can be achieved for up to eight CMOS memories.

See  the  data  sheet  for  the  DS1212  Nonvolatile  Controller  x  16  Chip  for  electrical  specifications  and operation.
