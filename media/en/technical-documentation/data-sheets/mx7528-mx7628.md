## CMOS Dual 8-Bit Buffered Multiplying DACs

## General Description

TheMX7528/MX7628containstwo8-bitmultiplying digital-to-analog converters(DACs).Separateon-chip latchesholdtheinputdataforeachDACtoalloweasy interfacetomicroprocessors.Thedataloadoperation issimilarto\_astaticRAMwritecycle.Dataisloaded using onlyCS,WR,and DACSelect(DAC A/DAC B) inputs.

EachDAChasaseparatereferenceinputandinternal feedbackresistorwhichallowfullyindependent operation while maintaining excellentDAC-to-DAC matching.

TheMX7528operatesfromasingle+5Vto+15V powersupply\_whereastheMx7628operatesfrom +12Vto+15V.TheMX7528hasTTLcompatibleinputs at+5Vsupply\_onlyandtheMX7628hasTTLcom-patibleinputsfrom+12Vto+15Vsupplies.

TheMX7528/MX7628issuppliedin20-leadnarrow DIP and Small Outline Packages.
