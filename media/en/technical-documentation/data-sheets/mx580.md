## High-Precision, +2.5V Reference

## General Description

The MX580 is a high-performance, three-terminal voltage reference which provides a stable +2.5V source for 8-, 10-, and 12-bit data converters and analog functions. A temperature-compensated internal bandgap operates from 4.5V to 30V and consumes only 1.5mA.

The reference can be connected directly to a number of CMOS analog-to-digital and digital-to-analog converters and is especially convenient in +5V powered systems. An initial untrimmed accuracy of 0.4% and temperature stability  of  10ppm/ ° C allow adjustment-free designs in many precision applications.

Available packages include TO-52 metal cans for commercial and military temperature grades, as well as 8-pin SO packages for commercial grade devices.
