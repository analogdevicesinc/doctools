## General Description

The MAX163,MAX164,and MAX167 are complete CMOSsampling12-bitanalog-to-digitalconverters (ADCs) thatcombine anon-chiptrack-and-holdand voltagereferencealongwithhighconversionspeed andlowpowerconsumption.Aconversiontimeof 8.33us includes settling time for the track-and-hold. An internal buried zener reference provides low drift withlownoise.

ThethreeA/Dsdifferonlyintheiranaloginputrange. TheMAX163accepts0Vto+5Vinputs,theMAx164 accepts -5V to +5V inputs,and the MAx167's input rangeis-2.5V to+2.5v.Externalcomponents are limited to only decoupling capacitorsfor thepower supplyandreferencevoltages.On-chipclockcircuitry caneitherbedrivenfromanexternalclocksourceor a crystal.

TheMAx163/164/167employa standardmicroprocessor interface. Three-state data outputs can be configured for 8- or 12-bit data buses. Data access and bus release timing specs are compatible with mostpopularmicroprocessorswithoutresortingto wait states.
